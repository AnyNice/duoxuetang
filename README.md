# 多学堂 DuoXueTang

**什么都能学的 AI 学习空间。** 想学什么就新建一门科目，AI 老师带你摸底、规划路线、一步步讲明白，再用练习、闪卡和复习把知识钉牢。名字取多邻国的巧思——学堂里什么都能学，多一门技能傍身。

![首页](docs/screenshots/home.png)

## 它能做什么

### 把一门新知识学完

- **四步课堂**：先摸底 → 按你的回答生成学习路线 → 每步先自己预测、再对照讲解 → 练习逐题按要点批改，错在哪、什么错因都说清
- **讲解带真图**：讲到流程、结构时老师会随文画图，不空说「如下图」
- **知识图谱**：知识点只有三种诚实状态（未学 / 学过未通过 / 已通过），只认真实判分，不编掌握度百分比
- **复习系统**：FSRS-6 事件账驱动，粗心和执行出错不算遗忘；闪卡从图谱自动生成
- **旁问**：上课时随时插嘴提问，不打断进度；标「还是不懂」会原地补前置概念
- **讲解朗读**：接微软 edge-tts 云端语音（晓晓等音色，多音字按上下文读），失败自动回退设备语音

### 快速学一门新知识

- **速成模式**：告诉它用途和可用时间（如「明天下午面试，3 小时」），先给一页纸总览搭骨架，路线只攻核心
- **费曼检验**：用自己的话把概念讲给老师听，它专挑你糊弄过去的地方追问
- **闪卡冲刺**：全科卡打包高速刷，刷完列出还生的卡和该回补的步，不干扰正常复习节奏
- **术语先行 / 速查表**：先扫生词；一键生成一页纸总结带走
- **跨科目类比**：讲解会拿你学过的科目打比方

### 笔记与导图

- **笔记库**：每节课由你点「生成笔记」，老师才整理；同一节课再点是增补进原笔记，不覆盖、不重复；生成时可选「易懂」（白话带例子）或「专业简洁」（只留干货）两种风格
- **思维导图**：笔记和知识点都能一键生成思维导图

![思维导图](docs/screenshots/mindmap.png)

### 导入与账号

- **导入知识点**：粘贴文本或上传文件（PDF / txt / md），内容被拆成知识点并入图谱，能学能出卡
- **账号系统**：注册 / 登录，数据按人隔离；第一个注册的账号自动接管已有数据
- **个人中心**：GitHub 式主页——学习热力图、学习统计、最近动态，可换头像；全局设置（模型 Key、朗读音色、资料目录）也收在这里

## 快速开始

需要 Node.js ≥ 18。

```bash
npm install
npm run build
npm start        # 打开 http://localhost:8080
```

Docker 部署：

```bash
docker compose up -d --build   # 默认端口 8090，可用 .env 里的 HOST_PORT 改
```

### 配置模型（必做，否则不能上课）

1. 注册并登录（第一个账号会接管已有数据）。
2. 进「个人中心 → 设置」，填 OpenAI 兼容接口的地址、模型名和你的 API Key（深度求索、通义、智谱、Agnes 等兼容接口都可以）。
3. 点「测试连接」确认可用，再保存。

所有数据都存在本地 `data/` 目录（SQLite 数据库 + 设置文件），已在 `.gitignore` 中，不会进仓库。API Key 只存你自己的机器。

## 技术栈

- 前端：Vite + React，双皮肤（多邻国风 / 语雀风）可切换
- 后端：Express + SQLite，单端口托管
- 教学引擎：任意 OpenAI 兼容大模型（BYOK 自带 Key）
- 复习调度：FSRS-6；语音合成：edge-tts（微软 Edge 朗读语音，免费免 Key）

## 已知限制

- edge-tts 是微软的免费朗读通道，非官方接口，偶尔可能不可用；不可用时自动回退浏览器设备语音
- PDF 导入只读文字层，无 OCR，扫描件会明确提示
- 语音听写依赖 Chrome 的 Web Speech API
